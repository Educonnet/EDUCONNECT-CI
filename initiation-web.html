Leçon 1 : Comprendre HTML

HTML sert à organiser le contenu d’une page Web : titres, paragraphes, images et liens.

Exemple de titre HTML :

<h1>Bienvenue sur mon site</h1>

La balise <h1> indique un titre principal.

Exercice : remplace le texte du titre par le nom de ton choix.

Leçon 2 : Découvrir CSS

CSS sert à mettre en forme une page Web : couleurs, tailles, espacements et disposition.

Exemple :

h1 {
  color: blue;
}

Cette règle demande au navigateur d’afficher les titres h1 en bleu.

Exercice : essaie de remplacer blue par red.
